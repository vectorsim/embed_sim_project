PMSM with PWM Inverter Interface, 3-Phase Current Sensors and Resolver Output

PMSM Motor with PWM Inverter Interface

Overview

Interior Permanent Magnet Synchronous Motor (IPMSM) modelled in the dq rotating reference frame, with a realistic PWM inverter interface for direct connection to a FOC controller outputting duty cycles.

Signal Chain

  FOC Controller
      | duty_a, duty_b, duty_c  [0..1]
      v
  Ideal 2-Level VSI Inverter (average-value model)
      | v_a, v_b, v_c  [V]  (w.r.t. virtual neutral)
      v
  Clarke Transform  (abc -> alpha/beta)
      v
  Park Transform    (alpha/beta -> dq, uses theta_e)
      v
  dq Voltage Equations (IPMSM dynamics)
      v
  Inverse Park      (dq -> alpha/beta currents)
      v
  Inverse Clarke    (alpha/beta -> i_a, i_b, i_c)

Sensor Outputs

  • i_a, i_b, i_c - three phase current sensors [A]
  • theta_m - resolver: mechanical rotor angle [rad]
  • emf_a, emf_b, emf_c - back-EMF per phase [V]

Inverter Average-Value Model

Valid when PWM switching frequency is much higher than the electrical time constants (typical for automotive: 10-20 kHz PWM vs ~1 kHz electrical bandwidth). The duty cycle represents the averaged phase voltage directly: v_phase_leg = duty * v_dc. Zero-sequence is removed by subtracting the virtual neutral: v_neutral = (v_a_leg + v_b_leg + v_c_leg) / 3.

Export as FMU (OpenModelica)

  loadFile("ThreePhaseMotor_PWM.mo");
  buildModelFMU(ThreePhaseMotor_PWM,
                version="2.0",
                fmuType="cs",
                fileNamePrefix="ThreePhaseMotor_PWM");

This produces ThreePhaseMotor_PWM.fmu ready for EmbedSim FMUBlock.

Typical Operating Conditions

  • DC bus: 48 V (automotive low-voltage)
  • Duty cycle at hover: 0.5 (zero net voltage)
  • FOC d-axis: duty near 0.5 (flux weakening)
  • FOC q-axis: duty deviation from 0.5 drives torque
